说明

- 这是一个使用 PyTorch 实现的线性回归最小示例。

依赖

- Python 3.8+
- torch
- numpy
- matplotlib

安装依赖（建议在虚拟环境中运行）:

```bash
pip install torch numpy matplotlib
```

运行

```bash
python D2L_Learning/pytorch_linear_regression.py
```

运行后会打印训练过程中的损失（每100个 epoch），并在当前目录生成：

- `pytorch_linear_regression.png`（拟合图）
- `linear_model.pth`（保存的模型参数）
